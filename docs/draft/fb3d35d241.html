2. この記事の主張

映画の税額控除は「その土地でどれだけ人を雇い、給与を払ったか」を基準に設計された制度であり、AI活用で制作人件費への依存が下がれば、補助金も、それを盾にした政治交渉も同時に効力を失っていきます。いまカリフォルニアで起きている争いは、制度が壊れる前の最後の綱引きとして読むべきではないでしょうか。

4. 本文下書き

補助金は映画ではなく、人件費に払われている

Forbesが8月19日に出した記事のタイトルが、この問題をほぼ言い切っています。「AIスタジオが制作人件費（production payroll）に依存しなくなるなかで、カリフォルニアは映画税額控除をめぐって争っている」。

映画の税額控除は、作品の芸術的価値に対して払われるものではありません。その土地で何人を雇い、いくら給与を払い、いくら現地で使ったか。それが給付の基準です。つまりこの制度は「制作費の大半が人件費である」という前提の上に建っています。

その前提が揺らぐと何が起きるか。制作費に占める人件費の比率が下がれば、同じ作品を作っても受け取れる控除額は減ります。逆に州から見れば、補助金を出しても以前ほどの雇用が地元に落ちてこない。誘致策としての費用対効果が両側から悪化していく構造です。

イギリスでは、7月14日にDeadlineが報じたScreenSkillsの見立てとして、インディー向け税額控除が業界に与えた効果は「modest gain（緩やかな改善）」にとどまるという評価が出ています。制度が万能でないことは、AI以前からある程度見えていたのかもしれません。

「出ていく」というカードの有効期限

8月12日、カリフォルニアは一日で騒がしくなりました。David EllisonがParamountをカリフォルニアから引き上げる可能性に言及し、州司法長官のBontaはこれを「恐喝の試み（blackmail attempt）」と呼びました。WGAも同様に批判し、ParamountのMakan Delrahimは州との和解について「すべてがテーブルの上にある」と述べています。民主党の知事候補Xavier Becerraもコメントを出しました。

この応酬は、雇用を人質にした交渉として読めます。スタジオ側は「雇用を持って出ていく」と言い、州側は「それは脅しだ」と返す。8月20日にCartoon Brewが報じた新レポートは、Paramount-WBD合併がロサンゼルスの制作雇用を大きく損ないうると警告しています。

ただ、ここで先ほどの論点が効いてきます。人質の価値は、人件費の大きさに比例します。AIによって制作の人件費依存が下がっていくなら、「雇用を持っていく」という脅しも、「雇用を守る」という大義も、年を追うごとに軽くなっていくのではないでしょうか。今の激しさは、カードがまだ効くうちの綱引きなのかもしれません。

連邦の控除は、この穴を埋められるのか

8月20日、Varietyは連邦レベルの映画税額控除を求めるハリウッドの動きを報じています。州同士の誘致競争が海外流出を止められないなら国single単位で、という発想です。

ただ、連邦控除も設計思想は同じでしょう。国内でいくら使い、誰を雇ったかに紐づける以上、人件費が縮む方向の技術変化には同じ弱さを抱えます。7月3日にはデンマークの新インセンティブ、7月12日にはボゴタのスタジオ拡張が報じられており、制作地の選択肢は増え続けています。補助金は場所の取り合いには効きますが、工程そのものが痩せていく変化には効きにくい。そこが違いだと思います。

買われているのは、制作費の削減分かもしれません

7月20日、NetflixがAI映画制作会社InterPositiveを買収したと報じられました（金額として$587 Millionという数字が関連報道に出ています）。7月4日にはByteDanceが自社のAI動画ツールをハリウッドの制作プロセスに組み込もうとしていると報じられています。

一方で8月12日には、ハリウッドが「slop janitors（AI生成物の後始末係）」を雇い始めているという論説が出ました。仕事が消えるのではなく、質の低い工程が新しく生まれている、という指摘です。

ここに、税額控除の設計が追いついていない現実があります。制度は「人を雇うこと」に報酬を出しますが、いま増えているのは制度が想定していない種類の労働で、減っているのは制度が支えてきた種類の労働です。カリフォルニアの争いは、誰が誰を脅したかの話ではなく、産業政策の測定単位が古びたという話なのだと思います。

5. X投稿案（3本）

A（切り口：制度の前提）

映画の税額控除は「その土地でいくら人件費を払ったか」に紐づく制度です。Forbesが8月19日に指摘したのは、AIスタジオがその人件費に依存しなくなっていること。作品を誘致する制度ではなく、雇用を誘致する制度だったからこそ、前提が崩れると効かなくなります。

B（切り口：対比）

8月12日、ParamountのCA撤退表明に州司法長官は「恐喝だ」と反発しました。雇用を人質にした交渉です。ただ人質の価値は人件費の大きさに比例します。AIで制作の人件費依存が下がるなら、脅しも大義も年々軽くなる。今の激しさはカードが効くうちの綱引きかもしれません。

C（切り口：現場で起きていること）

7月20日にNetflixがAI映画制作会社を買収、8月12日にはハリウッドが「slop janitors」を雇い始めたという論説。仕事が消えるというより、制度が想定していない種類の労働が増えている。税額控除は「人を雇うこと」に払われますが、その中身が入れ替わっています。
